# Eren Travel Agency – Frontend

## Overview
Eren Travel Agency is a frontend web project developed as part of a Web Technologies and Programming course.  
It represents a travel agency website where users can explore destinations and travel-related services through a responsive interface.

The project focuses on applying fundamental web development concepts to build a structured and user-friendly user interface.

## Project Purpose
- Practice frontend web development concepts
- Build a responsive website layout
- Apply basic UI/UX design principles
- Strengthen understanding of HTML, CSS, and JavaScript

## Technologies Used
- HTML
- CSS
- JavaScript
- Responsive Web Design principles

## Features
- Responsive layout for different screen sizes
- Travel agency landing page structure
- Organized sections for services and destinations
- Simple and clean user interface design
- Basic interactive elements (if implemented)
